## 阶段 2：实现、开发与负结果（已完成）

Task 1 尝试：

1. 自主混合高斯-类别 EM：每类 3/6/10 个潜在模式，原五折最佳约 0.916279。
2. 自主随机阈值森林：128 棵树，不做 Bootstrap，特征子集 10/18；未超过第一轮融合。
3. 类别支持专家：训练折内拟合最短 80% 气压区间，扩展系数 0.15/0.35，
   类别条件频率阈值 0.05；构造额外森林专家，对无支持的输入回退旧模型。
   最佳扩展 0.35、旧模型权重 0.25，原五折 Macro-F1=0.916855，第一轮为 0.916247。
4. 训练先验配额分配：自主最小费用分配算法经小规模穷举验证最优，但本地效果未优于
   不受约束方案，因此不推荐该候选，不把推测的测试均衡当作已知标签。

这些结果仍是小幅变化，没有找到大幅改善 Task 1 的证据。

Task 2 命令与流程：

```powershell

```

17/28 维残差组合器，原基模型曾使用该验证集选择轮数，因此不是完全独立外部测试。
固定 ridge=100，支持数收缩尺度 2/10/50，没有依据 Kaggle 分数调整参数。
