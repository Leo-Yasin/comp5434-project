# 第五轮：为什么同时加入语义和噪声通道

## 从已有方案继承什么

原词模型利用768万条训练评论，通过Dask分区计算自主岭回归；前几轮又加入了用户、
商品、重复文本的统计和浅层残差树。它们已取得用户报告的线上RMSE 0.59347。
本轮保留这些实际训练结果，再加入上下文语义和一个不同的概率训练目标。

词袋善于学习词频、短语与评分的平均关系，上下文模型能补充词序、否定和混合情绪的信息。
这里使用冻结的外部五星BERT网络，仅输出五个logits，未在本机微调网络。
最终评分由本项目自己的融合训练决定，不直接上传外部模型的预测。

## 两个分布必须区分

设潜在真实评分分布为 `q=(q1,...,q5)`。如果一条训练评分有epsilon概率被独立均匀替换，
观测标签分布为 `r=(1-epsilon)*q+epsilon/5`。epsilon=0.25时，真实评分必为5的评论，
观测为5的概率为0.8，观测为其他各评分的概率均为0.05，平均观测评分为4.5。

旧的逆通道校准从平均评分估计潜在期望；本轮的新分类器直接学习潜在分布q，
在计算训练损失时才经过噪声通道r。预测取 `1*q1+...+5*q5`，不用再次逆校准。
语义网络输出也是概率输入，不能盲目把其评分期望再逆噪声校正一次。

通道训练使用观测标签的负对数似然，解析梯度由项目代码推导：每条样本的常规softmax
梯度乘以 `(1-epsilon)*q_y / r_y`。这是在模型假设下“该观测来自干净通道”的后验权重。
模型认为不可信的观测影响较小，但不会人工删除记录或声称找出了真实错误标签。
整个噪声机制仍是假设，不能仅凭公式或合成实验认定比赛确实完全遵守该机制。

## 为什么增加有历史专家

无标签审计发现，原随机验证集44.36%的用户没有训练历史，而测试集用户、商品和父商品
都能在训练集中找到。因此，普通验证集全体风险与测试集所处条件有差异。

本轮除全体融合器外，另训练只面向三种身份均有历史记录的专家。门控由历史支持数决定，
缺历史输入回退全体模型。这个决定在查看语义效果前固定，并记录在实验协议中。
选择依据为内部“全部身份有历史”子集的噪声风险，同时保留全体与非显式星级子组结果。
这仅使身份支持条件更接近测试集，不保证其他分布完全一致。

## 如何防止验证结果被误读

57,797条语义样本由不同哈希位预先抽取，与标签和误差无关。内部检查5,802条用于选择；
组号1的28,879条用于冻结确认。旧模型的内部/确认预测按相应训练范围重建，
不能把已见确认标签的最终旧树用于确认基线。统计表和词模型始终排除原外层验证行。

历史几轮已复用这些组，所以它们不再是完全新鲜的独立测试。模型风险依赖噪声假设，
区间只描述固定模型/假设下的抽样波动；真正的Kaggle分数仍需用户提交后得到。
外部预训练语料是否含有相同评论未知，比赛是否允许外部模型也尚未核对。

## 源码阅读顺序

1. `semantic_prepare.py`：固定模型版本、来源哈希、输入文本与独立组抽样。
2. `semantic_infer.py`：分词、固定CPU量化网络、长度分组、断点及输出对应关系。
3. `semantic_fusion.py`：19维语义特征、历史门控、线性校准和旧模型划分重建。
4. `noise_softmax.py`：潜在分布、噪声通道、负对数似然及解析梯度。
5. `semantic_train.py`：内部比较、冻结确认、去语义消融、最终模型打包。
6. `semantic_predict.py`：从原始测试CSV独立重建全部特征与评分。
7. `semantic_uncertainty.py`：组级配对重采样，不用于反向选型。

实际命令见README，真实效果、时长和检查见根目录第五轮结果文档，不能用本说明替代实验结果。

本轮实际选中语义岭校准+400轮残差树。通道和有历史专家是实现并测试的对照路线，
没有被原内部选择；额外冻结审计也没有达到再发布通道候选的条件。
最终交付只有一个新CSV，不能把理论介绍中的全部路线都说成最终评分同时使用。
