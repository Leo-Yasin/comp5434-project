这是一次开发划分的比较，没有多种子显著性检验，也没有 Kaggle 成绩。

## 硬件与执行配置

- CPU：11th Gen Intel(R) Core(TM) i5-11300H @ 3.10GHz。
- 内存：15.74 GiB；逻辑 CPU 数 8。
- 单台机器，3 个 Dask 工作进程，每进程一个 Dask 线程，未使用 GPU。
- 底层 BLAS 线程数设为 1，避免与工作进程嵌套竞争。
- 环境版本与代码哈希见最终 manifest.json；缓存阶段记录了实际工作进程 PID。

## 并行效率比较

相同 600,000 条记录，执行相同训练核心算子，每配置重复 3 次。

| 工作进程 | 中位耗时秒 |
|---|---:|
| 1 | 1.4824 |
| 3 | 0.8227 |

三进程相对单进程中位加速比为 1.802。
结果包括任务调度、打开缓存、矩阵计算和有序归约，不含集群启动和方向广播。
各任务清理 Python LRU，但 OS 文件缓存与背景负载未完全控制；此值不是全量端到端训练加速比。
本次提升小于进程数增长；调度、内存带宽、I/O 与归约可能限制扩展，各项开销尚未分离测量。

## 复现与限制

- 六项核心测试通过，含空值解析、自包含标签隔离、验证标签隔离与 PCG 对直接正规方程解。
- 全部训练缓存与固定解析审计逐条核对，验证 RMSE 可从保存的预测重新计算。
- 独立模型包不依赖训练缓存或训练 CSV；独立 CLI 再次生成的提交文件逐字节相同。
- 独立原始 CSV 推理与缓存特征推理相同，所有测试 id/顺序/取值范围已核对。
- 没有额外重训整个大模型做逐权重比较，不宣称已进行该检查。
- 当前验证既用于比较方案也用于选择迭代次数，因此是开发成绩。
- 模型可能未完全收敛，哈希特征可能碰撞，冷启动与低评分误差需要进一步研究。
- 尚未上传 Kaggle；最终课程报告、团队贡献表和展示需结合 Task 1 一并整合。
