# 第十轮：冻结标题语义的理解与复现

本分支尚须内部和固定确认均优于第九轮才推荐，实际决定见根目录第十轮记录。
此前真实Kaggle最佳0.50646属于第八轮；第九/十轮本地风险不代表线上分数。

## 模型原理

正文和标题分别使用同一来源的英语DeBERTa。标题分支的全部12层均冻结，输出768维CLS和五星logits。
它可以保留“并不适合敏感皮肤”等标题语义，而不仅限于原先少量星级/词面结构特征。
前层注意力把词与相对位置结合，最后CLS汇总上下文；五星分布是模型预测，不被当作干净答案。
网络仍是MIT固定版本06f020e0dbf909570eb886423bd3af256b855546，训练语料信息不完整、重叠未知。
不调用外部评分API，不引入外部用户/商品评分答案；自然包含星级文字的标题只是课程提供的输入特征。

第九轮类别分布为`q9=(1-alpha9)*q8+alpha9*q8_corrected`，期望正好等于第九轮连续评分。
新头以`log(q9)`为固定偏置，在标题logits/分布、可选CLS和旧结构上学习残差，再以均匀替换噪声似然训练。
低维/高维头的L2以及评分融合系数仅在固定8候选中选择；所有标准化/标签拟合仅用对应允许训练组。
最终输出五星分布的连续期望，再与父评分融合；不取整数argmax，也不对期望重复逆噪声校正。

## 数值及验证

先对16条内部拟合标题比较原CPU ONNX与GPU完整模型，达到数值门槛后才能生成选型输入。
最终残差头拟合后再比较同一批CPU/GPU表示的实际连续评分差，防止特征标准化放大微小数值差异；未通过不发布。
标题缓存完全不读评分；监督残差头分别使用33437/41705/83047行。
标题本身没有课程监督，但第九轮父预测在当前拟合行并非OOF；新头仍可能受训练内/外预测差异影响，冻结标题不等于整条融合链都交叉拟合。
内部检查8268行冻结后才评估41342确认行；历史分组有复用，bootstrap只提供条件区间。
不依据确认结果重选8项中的其他方案。若新分支未胜出，继续使用第九轮候选。

## 队友预测

完整模型包另行复制为`task2/latest/model`。里面含完整第九轮父包、标题残差头、选择配置及逐文件SHA。
标题网络直接复用父包已有的原英语模型，不需要再下载另一套权重。
模型包在本机C盘；参数可用同卷硬链接节省空间，复制到队友电脑后按普通文件读取。
环境沿用第九轮：数值Python、旧BERT CPU环境、英语CPU环境（含官方torch2.6.0）。

```powershell
python -m task2.round10_predict --model task2/latest/model --test comp-5434-20261-project-task-2/test.csv --semantic-python .venv-semantic/Scripts/python.exe --english-python .venv-english/Scripts/python.exe --work-dir task2_inference_round10 --output task2_prediction_round10.csv
```

预测读取原始CSV和完整模型包，不读取训练缓存或旧提交评分。
输入、模型、分词器和运行时一致时可复用冻结编码；父评分和最终评分均重新计算。
原始标题通过单独文本CSV进入英语模型，空字符串和字面量None保持既定CSV解析语义。
计时记录标题/前缀复用行数，不把缓存核验耗时称作全新端到端编码速度。

本轮测试标题首次由本地GPU生成FP32冻结表示，单独记录真实GPU耗时。
可选缓存协议`verified_cuda_title_fp32_v1`绑定原英语ONNX的固定SHA、分词器、原始输入、输出SHA、行数及CPU/GPU精度证明。
该协议明确标记CUDA来源，绝不把它伪装成CPU新编码；不匹配或未完成则拒绝。
独立原始CSV预测可以复用该无标签表示，但会重建父模型和最终评分；没有缓存时仍完全使用CPU ONNX编码。
本机32条256token输入的单/四线程逐位一致，但完整动态长度10000行出现最大2.958e-7舍入差；正式和独立路径因此统一四线程，并仍按原1e-8门槛检查。跨不同硬件的冷启动结果允许正常浮点误差。
