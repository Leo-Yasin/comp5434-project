## 阶段 3：并行流程与自主模型（2026-10-19，已完成）

框架选定 Dask distributed.LocalCluster，三个工作进程，每进程一个 Dask 线程。
官方依据：https://docs.dask.org/en/latest/user-interfaces.html 与 https://docs.dask.org/en/latest/scheduling.html 。
课程允许使用其他大数据并行框架，本实现让 Dask 实际执行全量特征任务和训练矩阵运算。

1. `python -m task2.prepare`：CSV 由流式解析器正确处理带换行评论，50,000 条一块，
   并行任务队列有界，缓存标题/正文一元和二元词组的稀疏哈希特征。
2. `python -m task2.target_stats`：分别生成 split 和 full 统计；训练行的用户/商品统计采用
   五折交叉拟合，排除自身所在整折；验证行只使用外层训练标签。
3. `python -m task2.train`：自行实现带正则项的评分回归与预条件共轭梯度，
   各工作进程计算 X_k.T(X_k p)，主进程按固定顺序归约并更新参数。
4. 比较全局均值、元数据、文本及混合方案，连续预测截断到 [1,5]，不取整。

HashingVectorizer 仅用于文本转换，没有调用现成评分预测模型。
所有评分统计、交叉拟合、目标函数、优化迭代与归约逻辑均由项目代码实现。

已完成的准备与核对：

- 154 个训练分块，三个实际特征工作进程 PID 为 6440、16640、17024。
- 文本缓存准备约 334.35 秒；含 479,039,323 个非零项。
- 将 CSR 转换为映射数组，额外约 3.6 GiB，转换及逐元素核对约 70.26 秒。
- split 统计准备约 18.02 秒，full 统计准备约 19.61 秒。
- 六项核心测试通过，覆盖解析兼容、标签泄漏隔离、平滑回退、PCG 数值解及特征确定性。
- 全部 7,684,645 条缓存分组与修正后的审计一致，不只是抽样比较。
