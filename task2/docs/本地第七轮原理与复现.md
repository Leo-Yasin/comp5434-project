# 本地第七轮：不依赖云端GPU的两条路线

日期：2026-11-14。继续继承冻结BERT和此前Dask词模型，BERT权重没有更新。
线上基准为用户反馈的0.53985；本地风险估计不等于新的线上分数。

## 后验历史

1. 从已有普通/Huber词模型中取纯文本部分，不重复输入用户、商品均值。
2. 用开发训练部分的含噪标签，拟合项目自定义五星噪声通道分类器，得到干净先验q。
3. 假设观测评分y以epsilon概率被均匀随机替换。未替换的后验责任为
   `w=(1-epsilon)*q[y]/((1-epsilon)*q[y]+epsilon/5)`。
4. 潜在真值分布为`w*onehot(y)+(1-w)*q`。可信评分接近原值，可疑评分回退文本先验。
5. 分块聚合用户、商品、父商品的后验五星分布、二阶矩和可信度，并构造多种收缩尺度。
6. 在旧第六轮预测上学习残差；未知身份没有新表时回退旧模型。

开发归约排除全部原153456条验证记录。每阶段校准器也只拟合相应训练子组。
训练部分的词预测是样本内预测，可能过于乐观，因此需要留出比较。
同模型去掉历史的消融表明：本轮该路线的大多数改进来自重新学习组合器，不能全部归功于去噪。
新表仅保存事先请求身份，选择依赖输入ID，不依赖其评分；不能把包说成覆盖全部457万用户的新表。

## 全量稀疏五星分类

与原均值回归不同，新模型的参数是`294929×5`权重和5个偏置。
HashingVectorizer只生成词/基本特征，训练损失、梯度和预测由项目自行实现。
潜在分布`q=softmax(XW+b)`，观测分布`r=(1-epsilon)*q+epsilon/5`，优化`-sum log(r[y])+L2`。
对logits的梯度为`w*(q-onehot(y))`，随机替换嫌疑大的标签对梯度贡献自动减小。
三个真实Dask工作进程计算各自分区的损失和梯度，主进程固定顺序归约，通用L-BFGS更新参数。

列平方和的Jacobi变量缩放只改变数值参数化，不改变原目标函数。模型文件保存恢复原坐标的W，
独立预测无需优化尺度文件。每阶段词特征不读取查询标签，训练排除原外层验证记录。
本轮若使用split权重部署，实际词分类训练7531189行；测试数值历史来自原full表。
这不等于对全部7684645行重新拟合五星词分类器。

新五星分布提供给旧第六轮logits上的噪声残差头；内部组只比较预先指定的两个检查点、
两个L2值及两种融合幅度，选型后冻结，再检查组1。未通过就不发布该路线。

## 代码入口

- `history_prepare.py`：从稀疏缓存提取两种纯文本评分。
- `posterior_history.py`：后验、历史归约与72列新特征。
- `history_train.py`：历史路线分阶段拟合和验证。
- `sparse_noise.py`：自主Dask五星文本分类。
- `sparse_fusion.py`：新分布和旧BERT头的融合。
- `local7_predict.py`：原始CSV和自包含模型包独立预测。
- `tools/finish_task2_local7.py`：打包、组级不确定性、提交格式和旧文件校验。

开发训练依赖原有缓存和前六轮产物，不把最终预测命令宣传为从零训练命令。
预测只需要对应完整模型包、数值Python3.9、ONNX语义Python3.12及原始CSV。
本地完整模型在`task2/outputs/round7_local_20261114/model_<路线>`，大型参数不纳入Git。

```powershell
python -m task2.local7_predict --model task2/outputs/round7_local_20261114/model_history --test comp-5434-20261-project-task-2/test.csv --semantic-python C:/Users/Leo/.cache/comp5434-round5/venv/Scripts/python.exe --work-dir task2_inference_local7 --output task2_prediction_local7.csv
python -m unittest discover -s task2/tests -v
```

若使用五星融合路线，模型目录名改为model_sparse；以结果报告中实际通过的路线为准。
推理时ONNX断点会核对输入、模型、分词器和批量配置指纹，不能混用不同文本或网络的缓存。
