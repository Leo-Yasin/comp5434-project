## 阶段 1：需求与数据确认（2026-10-19）

- 输入目录：`comp-5434-20261-project-task-1/`，包含 train、test、sample_submission。
- 训练集 9,900 条；测试集 3,300 条；七个数值特征、三个类别特征。
- 四类训练标签各 2,475 条，完全均衡，第一版不使用类别权重。
- 未发现缺失值、特征完全重复记录、训练测试间完全相同特征记录或测试新类别。
- 存在湿度/降水大于 100、极端温度与气压；测试集也有类似值，保留原值。
- 特别问题：训练 label 为 1–4，而样例 label 为 Rainy。暂时同时输出整数与天气名称两种编码，等待核对 Kaggle；不自动上传。

完成标准：通过字段、标签范围、id 唯一性及样例顺序检查，并保存原始文件 SHA-256。

## 阶段 2：验证协议与自主算法（2026-10-19）

- 固定种子 5434，使用相同的分层 5 折，保存每条记录的折号。
- 每折独立学习中位数、标准化参数和独热编码词表，id 不作为特征。
- Softmax：手写稳定 softmax、交叉熵、L2 正则与全批量梯度下降。
- Softmax 早停在外层训练折的内部 15% 留出集上进行；选轮数后从零训练外层训练折，外层验证不参与早停。
- CART：手写 Gini、排序加累计计数的阈值搜索、递归建树及叶子概率。
- 随机森林：手写 Bootstrap、每个节点 sqrt(d) 特征抽样与树概率平均。
- 初始配置预先固定：CART 深度 12、叶子最少 5 条；森林 80 棵、深度 16、叶子最少 3 条。
- 只依赖 NumPy/pandas 等底层能力，不调用现成分类器。

完成标准：数值梯度、手算指标、分层划分、预处理隔离、树分裂及保存加载一致性测试通过。

## 阶段 3b：异常标记消融（2026-10-19，已完成）

运行目录：`task1/outputs/forest_flags/`。
保持折号、种子、80 棵树、深度和叶子限制相同，只增加四个预先定义的异常标记。
注意：增加特征会改变随机子集抽样的具体结果；该比较衡量整个特征方案的效果，
不能将全部差异都解释成异常值本身的因果贡献。

实际执行命令（均从项目根目录执行）：

```powershell
python -m task1.run --output-dir task1/outputs/baseline
python -m task1.run --models forest --anomaly-flags --output-dir task1/outputs/forest_flags
```

实测 5 折 Macro-F1 均值与折间样本标准差：

| 方案 | 均值 | 标准差 |
|---|---:|---:|
| Softmax | 0.866689 | 0.007396 |
| CART | 0.903955 | 0.005070 |
| 随机森林 | 0.915223 | 0.001679 |
| 随机森林 + 异常标记 | 0.914683 | 0.003409 |

结论：暂保留基础随机森林。加入标记的均值变化为 -0.000541，差异较小，未做显著性检验。
基础森林全量训练 7.886 秒，3,300 条测试记录预处理与推理合计 0.215 秒；这是本机单次实测。
Softmax 所有内层选择都达到 1000 轮上限，因此不能声称线性基线已充分调优。
详细分数、混淆矩阵和错误分析见 `实验总结.md` 及各运行的 `results.md`。
