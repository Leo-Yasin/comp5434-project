# Task 1 模型设计与实验协议

## 输入与目标

输入为七个数值字段和云量、季节、地点三个类别字段，预测四种天气。
内部标签对应关系：1 Sunny，2 Cloudy，3 Rainy，4 Snowy。
id 只用于对齐记录及导出提交，不能作为天气特征。

## 预处理

数值缺失值用当前训练部分中位数填补。Softmax 使用训练均值和标准差进行标准化，
树模型保留原始数值。类别字段按当前训练部分的词表独热编码，并额外预留未知类别列。
在当前数据中没有缺失值，也没有测试集新类别，但预留处理保证流程边界明确。

保留异常数值；异常标记实验增加湿度 >100、降水 >100、温度 >60、气压不在 [900,1100]
四个二值特征。它们是实验假设，不代表已确定的数据错误。

## Softmax 回归

计算 logits = XW + b，每行减去最大 logit 后求 softmax 概率。
目标为平均交叉熵 + (lambda/2) * sum(W²)，偏置不正则化。
令 P 为概率、Y 为独热标签、n 为样本数，则：

```text
dW = X.T @ (P - Y) / n + lambda * W
db = sum(P - Y, axis=0) / n
W  = W - learning_rate * dW
b  = b - learning_rate * db
```

采用全批量梯度下降，零初始化，初始学习率 0.15、L2 系数 0.001、最多 1000 轮。
零初始化对线性 softmax 是有效的，不存在隐藏神经元的对称性问题。
训练折内部再分层留出 15% 用于验证交叉熵早停，耐心值 60 轮。
选择最佳轮数后，重新拟合整个外层训练折；全量训练取五次所选轮数的中位数。

## CART 分类树

节点 Gini = 1 - sum(p_c²)。选择使子节点加权 Gini 最小的特征与阈值。
各候选特征排序后，用类别累计计数计算所有合法切分点的左右样本计数：

```text
weighted_gini = 1 - (sum(left_counts²)/n_left + sum(right_counts²)/n_right) / n
```

相同取值之间不能切分，左右都必须满足 min_leaf。纯节点、深度上限、样本不足或
没有正增益时停止。叶子保存四类经验概率。初始配置 max_depth=12、min_leaf=5。
预测取概率最大的类别；如概率相同，固定取编号较小的类别。

## 随机森林

1. 每棵树从训练记录中有放回抽取 n 条记录，即 Bootstrap。
2. 每个节点随机抽取 floor(sqrt(d)) 个特征，在这个子集中执行 CART 阈值搜索。
3. 对全部树的叶子类别概率求算术平均，再选择概率最大类别。

初始配置为 80 棵树、深度 16、叶子最少 3 条记录。抽样和树种子均由固定生成器确定。
实现为单机顺序训练，不把线程数或服务器数量作为本阶段的实验变量。
Gini 重要性为各特征的样本数加权不纯度减少量，再归一化；不作因果解释。
